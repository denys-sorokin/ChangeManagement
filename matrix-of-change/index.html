Matrix of Change

Map how today's practices and the practices you want to introduce reinforce or compete with each other, read how hard the transition will be, and plan what each practice turns into.

How the Matrix of Change works

Four steps

  1. List the practices. Existing practices describe how the organisation works today. Target practices describe how it should work after the change. Group related ones, for example Information systems, Services, Organisation.
  2. Compare each system with itself. In the left triangle, mark how existing practices interact with each other. In the top triangle, do the same for target practices. Each diamond is where the diagonals of two practices meet.
  3. Compare the two systems. In the square transition matrix, mark how each existing practice (row) interacts with each target practice (column).
  4. Read the result. Check coherence, where to start, greenfield or brownfield, and the pace of change. Then decide what to keep, transform or phase out.

Signs

  • +Complementary. Doing more of one practice makes the other more valuable.
  • −Competing. The two practices work against each other.
  • ++Strong versions of either sign, when you want to show intensity.
  • Blank. No clear evidence either way.

A plus sign does not mean an interaction is “good”, only that it is reinforcing. Try the UPS or GM example in step 01 to see a finished matrix.

      Read the results

      The readings update as you mark the matrix. They follow the questions the Matrix of Change was designed to answer: feasibility, sequence, location, pace and stakeholders.

        These readings apply simple rules of thumb to your signs. Use them as prompts for your own argument, not as answers.
