Business Model Canvas

Write straight onto the nine blocks of the canvas. Give each idea a short title, add a smaller description below, mark what is new with the transformation, and download the result for your slides or report.

How to use this canvas

Writing

  • Click any block and type. The first line is a main idea in bigger text.
  • Press Enter at the end of a main idea to write its description in smaller text. Use the toolbar to switch a line back to a main idea.
  • Use bold, italic and bullets for detail.
  • Mark as new highlights items that are new or change with the transformation. The workgroup asks you to show the impact of the new practices on the canvas, and this makes it visible.

A good order to fill it in

  1. Customer Segments and Value Propositions
  2. Channels and Customer Relationships
  3. Revenue Streams
  4. Key Resources, Key Activities and Key Partners
  5. Cost Structure

Planning a transformation? Map the practices first with the Matrix of Change, then bring the new practices into this canvas.
